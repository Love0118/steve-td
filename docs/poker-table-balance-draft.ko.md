# 포커 테이블 기본 밸런스 시안

아직 게임 코드에 등록하지 않은 검토안입니다. 설치 비용 100다이아, 중반 앞라인, 한 번의 포커 베팅으로 최종 성능을 결정하는 방향입니다. 비교 수치는 현재 소스 기본값이며 실제 서버 설정은 확인하지 못했습니다.

## 비교 기준

| 타워 | 설치부터 필요한 비용 | 체력 | 공격력 | 공격 간격 | 비고 |
| --- | ---: | ---: | ---: | ---: | --- |
| 주민 눈 골렘 | 100 | 120 | 5 | 20틱 | 직접 설치 가능한 기본 앞라인 |
| 언데드 좀비 | 95 | 100 | 5 | 15틱 | 흡혈과 처치 버프 보유 |
| 군대 위병 | 50 | 230 | 6 | 20틱 | 군대의 기본 앞라인 |
| 군대 GOP 초병 | 150 | 450 | 10 | 19틱 | 50 설치 + 100 강화, 주변 짬 성장 감소 |
| 천둥 접지 아르마딜로 | 150 | 300 | 15 | 19틱 | 50 설치 + 100 강화, 전력 소모·접지 효과 |

카탈로그상 100다이아인 상위 타워라도 기존 설치비가 추가되므로, 직접 설치 100다이아와 구분했습니다. 빌더마다 기본 스탯 편차가 커서 단순 평균을 사용하지 않습니다.

## 제안

| 항목 | 기본값 시안 |
| --- | ---: |
| 설치 비용 | 100다이아 |
| 최대 체력 | 150 |
| 일반 공격력 | 0 |
| 마법 공격력 | 0 |
| 공격 간격 | 공격하지 않음 |
| 사거리 | 0 |
| 어그로 우선순위 | 80 |
| 기본 피해 감소·회복 능력 | 없음 |

공격 요소를 제거한 순수 앞라인으로 구성합니다. 직접 설치비가 같은 눈 골렘의 체력 120보다 25% 높은 150을 초기 제안으로 잡았습니다. 일반·마법 평타와 공격형 강화는 없으며, 강화 보상도 체력과 생존 능력에 집중합니다. 특수 생존 능력은 좋은 패의 보상으로 남깁니다. 저성능 결과의 10~30%는 기본 능력치를 깎는 뜻이 아니라 정상적으로 받을 추가 강화량의 10~30%로 해석한 시안이며, 최종 구현 전에 이 기준을 명확히 해야 합니다.

앞서 정한 베팅 상한 1,000다이아, 타워당 1회, 8 하이 이하 파괴, 9~J 하이 대실패, Q 하이~원페어 일반 강화, 플러시 이상 최대 강화+특수능력은 유지합니다. 대실패 문구는 `타워가 븅신같이 강화됐습니다`입니다. 베팅액별 증가 계수와 특수능력은 아직 확정하지 않았습니다.
